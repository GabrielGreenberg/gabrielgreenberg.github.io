VIRGIL

AI-native visual LaTeX editor for academic writing.

Created by Gabriel Greenberg.   Version 0.1.136   GitHub

Install Virgil from Chrome.

Write.

  1. Install Virgil.Requires Chrome.
  2. Open or create project folder in Virgil.Overleaf users: sync locally with Dropbox.
  3. Use Virgil to write and compile.Use Claude or Overleaf for complex compile tasks.

Edit.

  1. Leave AI-requests in Virgil.
  2. Open project folder in Claude.
  3. Ask “Virgil” to review your requests, or start a new task.
  4. Review and approve changes in Virgil.

Cite.

  1. Create a Virgil-Library folder.
  2. In Claude, ask Virgil to build your master bibliography.
  3. Connect the Library folder within Virgil.
  4. Cite articles by name from the Virgil editor. Virgil takes care of the bibliography.Try the \cite command.

Research.

  1. Populate Virgil-Library with pdfs.
  2. In Claude, ask Virgil to index your pdfs.Use deep-index to extract structured text.
  3. In Virgil, ask for research targeted at specific articles.
